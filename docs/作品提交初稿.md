### 本作品核心主张

- **本作品针对的具体问题**：面对开放科学问题时，直接问答式大模型输出存在“四无”缺陷——无文献证据约束、无量化证伪条件、无可执行研究计划、无自我修正闭环；且检索证据易被单一来源垄断、在线文献接口易触发限流，导致假设生成不可复现、不可追溯。
- **本作品实际完成的核心方法**：Explorer→Scientist→Critic 三智能体结构化闭环（知识缺口识别 → 可溯源证据组织 → 3条可证伪候选假设+三层研究计划 → 五维评审+缺陷/反事实输出 → 反馈迭代，上限3轮）；离线证据层（OpenAlex 125题×5篇预采集去重入 Chroma + 142篇本地 arXiv PDF 全文切分入库）+ arXiv 动态保底检索（hybrid_retrieve 分来源融合，保证≥1条在线文献）；V2/V3 迭代复用 V1 Explorer 检索结果防止证据漂移，Scientist 强制锚定已有证据集禁止虚构文献，Critic 采用相对改进评分原则关注维度提升幅度而非绝对分数；全部中间结果以 JSON 快照持久化，可追溯、可复现。
- **最有代表性的结果1（对象、口径、结果）**：对象=代表题“人类情绪起源于哪里？”；口径=Critic 五维评分+计划粒度 L1–L3；结果=V1 综合 7.53 → V2 综合 8.29，其中证据维度 6.8→7.8、可证伪性 8.2→9.2、跨学科 7.0→8.1；V2 三条假设均含量化证伪阈值（n≥25/30/35、p<0.01、latency<280ms 等）与“竞争机制排除”实验设计。
- **最有代表性的结果2（对象、口径、结果）**：对象=官方125题证据层；口径=全量离线采集+去重+入库统计；结果=125/125 题完成、625篇论文（每题恰5篇、0缺失）、593篇唯一、1337 chunks 入 Chroma，每篇含 DOI/openalex_id 等可溯源字段；前端证据表仅展示 arXiv/openalex 可溯源来源。
- **目前仍存在的主要局限**：① 生成层尚未完成125题全量批跑（证据层已全覆盖，批跑脚本与接口已就绪，提交前补齐）；② 假设与研究计划仍为“计算方案”层级，实验验证需领域专家与真实实验条件；③ 证据以英文文献（OpenAlex/arXiv）为主，中文文献覆盖不足；④ Critic 评分为模型自评，尚缺人工专家盲评对照。

## P2｜作品目标与实际完成内容

### 团队实际解决的问题
现有“大模型直接回答科学问题”的方式存在四项具体不足：一是假设没有文献证据约束，引用不可追溯，模型可能编造来源；二是假设停留在定性叙述，缺乏量化的可证伪条件，无法指导真实实验；三是一次性问答没有评审与修订闭环，错误与偏颇无法自我修正；四是证据检索容易被单一本地来源垄断（本项目早期版本 top-5 证据全部被 Science_2025 背景块占满，在线文献参与率为0），且在线接口（arXiv）在高频调用下触发429限流导致流程中断。本作品解决其中的全部四项：以“证据与假设分离+引用 chunk 级对应”解决不可追溯，以 schema 强制 falsification_condition/verification_criteria 解决不可证伪，以 Critic 反馈迭代解决无闭环，以 hybrid_retrieve 分来源融合+限流退避解决证据垄断与接口不稳定。

### 本作品实际完成的工作
已实现：科学问题理解（中英文翻译、关键词限词、问题骨架 problem_skelton 提炼）；知识缺口识别（knowledge_gaps 列表）；证据组织（OpenAlex 离线库+Science_2025+本地 arXiv PDF 全文+arXiv 动态保底的分来源融合检索，evidence_list 含 claim/source/year）；候选假设生成（Scientist 每轮3条，含形成依据、支持推理、量化证伪条件、L1概念/L2定量/L3稳健性三层研究计划、confirm/reject 双阈值验证标准；迭代时强制锚定已有证据集，禁止脱离证据虚构文献）；假设比较筛选（Critic 五维评分+cross_hypothesis_comparison 差异化比较；迭代时采用相对改进评分原则，关注薄弱维度突破与优势维度保护）；研究计划形成与反馈修订（/api/feedback 触发 V2/V3，V2/V3 复用 V1 Explorer 检索结果防止证据漂移，Critic 缺陷与反事实自动进入下轮上下文）；全部轮次快照 JSON 持久化与前端可视化（Explorer 证据面板、报告页、Markdown 导出）。未实现：湿实验/临床数据的真实验证（超出本作品边界，已在局限中声明）。

### 总体思路

```
科学问题 →(Explorer) 知识缺口+跨学科类比 →(hybrid_retrieve) 科学证据[openalex∪Science_2025∪arXiv(保底≥1)]
→(Scientist) 候选假设×3(含证伪条件+三层计划) →(Critic) 比较筛选(五维评分+缺陷+反事实)
→ 研究计划 →(反馈: Critic评审/人工意见) 修订 → 下一轮 Scientist …(上限3轮) → 快照持久化
```

- **本作品最终形成的主要输出**：每轮一份结构化快照（V{n}.json），含问题骨架、证据列表、知识缺口、类比、3条候选假设（7字段完整）、跨假设比较、Critic 五维评分+top_flaw+counterfactual+missing_evidences、综合分与粒度分；前端报告页与 Markdown 导出。
- **本作品已使用官方125道科学问题完成的实际测试**：证据层全量测试 125/125 题（每题5篇、0缺失、593唯一、1337 chunks 入库）；生成层完成代表题“人类情绪起源于哪里？”V1+V2 完整两轮闭环；125题生成层批跑【待补：提交前执行并导出逐题结果文档】。
- **相较直接使用大模型回答，本作品最主要的不同**：直接问答只给“结论性叙述”（见 P18 对照：qwen-plus 零样本直答3条假设，0文献引用、0量化证伪阈值、0研究计划）；本作品给出“可审计的候选方案包”——每条假设可追溯到具体文献 chunk，可被量化条件证伪，可被评审迭代修正，并明确标注“候选、待验证”。

## P3｜本作品采用的科学逻辑与假设生成原则

### 团队实际采用的判断原则

| 科学判断环节 | 本作品实际采用的做法 | 采用该做法的理由 |
|---|---|---|
| 区分已有事实、文献解释与模型推断 | evidence_list 每条带 source+year（openalex/arXiv/Science_2025）；knowledge_gaps 单列“未知”；analogies 单列“跨学科类比”并写明 mapping_relation；Scientist 每条假设的 source 字段必须声明其基于哪些证据/缺口/类比 | 让事实、文献解释、模型推断三类内容在数据结构上物理分离，评审与人工可逐条审计边界 |
| 将知识缺口转化为候选假设 | Explorer 输出 knowledge_gaps 列表；Scientist prompt 要求假设逐条回应缺口，且 source 字段强制引用缺口或证据 | 防止假设凭空生成，保证每个假设都有明确的“问题锚点” |
| 保证候选假设可检验或可证伪 | Pydantic schema 强制 falsification_condition 与 verification_criteria(confirm/reject) 字段，缺失即结构化输出失败并自动重试（每智能体≤3次） | 可证伪性是科学假设与臆测叙述的分界线；schema 强制比 prompt 劝说更可靠 |
| 保留反对证据和替代解释 | Critic 强制输出 top_flaw/counterfactual/missing_evidences；V2 起假设须含“竞争机制排除”设计（如 β 频段对照、非OXTR通路、失语症天然消融） | 防止确认偏差；V1→V2 实测证明该机制直接提升可证伪性 8.2→9.2 |
| 避免把候选假设写成已证实结论 | 全部输出标注“候选假设”；Critic 评分仅评价方案质量而非真值；文案与报告页显式声明“需研究者审查” | 符合科学伦理与赛事要求，避免夸大 |

### 本作品的科学逻辑
问题中的**研究对象与关键变量**由 Explorer 的 problem_skelton 与 evidence_list 提取（如代表题中“脑网络同步性/表观遗传调控/生理信号解码/语言标注”四个变量）；**知识缺口**（knowledge_gaps）决定假设的切入点；**证据**（evidence_list）作为 supporting_reasoning 的约束项，Critic 的 evidence 维度专门核查假设与证据的一致性；**支持/削弱/否定**的判定被前置写入每条假设的 verification_criteria：confirm 阈值达成即支持、reject 阈值达成即否定、Critic 的 counterfactual 给出“何种观测会同时推翻多条假设”的组合否定条件。因此“什么结果支持或否定假设”在生成时即被显式定义，而非事后解释。

### 证据处理方法
- **本作品如何判断来源是否可用**：来源白名单（arXiv/openalex/Science_2025/本地PDF）；每条入库 chunk 的 metadata 必须含可溯源标识（arxiv_id/openalex_id/doi 或官方题册 ID）与 source/year/title；摘要无法重建（倒排索引为空）的论文不入库。
- **遇到证据不足或相互冲突时，系统实际如何处理**：arXiv 失败时 hybrid_retrieve 以离线库兜底，保证证据列表非空且不中断 pipeline；冲突证据（如“定位主义 vs 建构主义”）并列保留在 evidence_list 中，由 Critic 在 detailed_review 中显式讨论，系统不自动仲裁；Critic 的 missing_evidences 把“缺什么证据”显式输出交人工补充。
- **本作品如何保留引用和科学证据之间的对应关系**：chunk 级入库，metadata 记录 source/year/title/ID；Explorer 输出 claim–source–year 三元组与 chunk 一一对应；前端证据表、报告页与 Markdown 导出仅展示可溯源来源（arXiv/openalex 正则过滤），Science_2025 仅在后端参与生成、不进入展示层引用表。

### 评价口径说明
- **团队重点评价的是哪些方面，为什么**：可证伪性与证据强度。方向1A 的核心是“假设生成与研究计划设计”，假设是否可被量化条件否定、是否有可溯源证据支撑，决定其科学价值；新颖性与跨学科性作为加分维度。
- **评价由程序、模型、团队成员或领域专家中的哪些主体完成**：程序（溯源统计、粒度统计、轮次对比）+ 模型（Critic 五维评审）+ 团队成员（代表案例审阅、最终判断与文案定稿）。
- **第一轮与第二轮是否采用同一口径；如有变化，原因是什么**：五维评分维度与 L1–L3 指标不变，保证分数可比；V2/V3 起 Critic 额外注入相对改进评分原则（关注提升幅度、保护优势维度、聚焦薄弱突破），解决早期版本绝对标准过严导致迭代分数不升反降的问题。
- **什么情况下继续生成、停止或交由研究者判断**：上限3轮；Critic 指出的缺陷若属于“需真实实验数据才能裁决”（如 V2 指出的 H2 因果方向问题）则停止迭代、交研究者判断；overall 连续两轮提升<0.2 停止。

> 模板提示：可参考相关性、证据一致性、可检验性、可证伪性、假设多样性和研究计划可执行性，但不要求全部采用。（本作品采用：证据一致性、可检验/可证伪性、多样性[cross_hypothesis_comparison]、计划可执行性[粒度L1–L3]）

## P9｜候选假设生成方法

### 本作品实际采用的生成机制

| 生成环节 | 本作品实际做法 | 该设计解决的具体问题 |
|---|---|---|
| 从知识缺口形成候选解释 | Scientist 每条假设 source 字段声明基于哪些 gap/证据/类比；迭代时强制锚定已有证据集，source 必须引用已提供的证据来源之一 | 假设凭空生成、迭代中脱离证据虚构文献 |
| 生成多个可区分的候选假设 | schema 要求3条并强制 cross_hypothesis_comparison 说明差异维度 | 单一视角、同质化 |
| 将支持、反对证据纳入生成 | supporting_reasoning 引用证据；V2 起须含竞争机制排除设计 | 确认偏差 |
| 控制重复、空泛或不可检验输出 | falsification_condition/verification_criteria 强制字段+失败重试 | 不可证伪、空泛 |
| 形成统一的候选假设表达 | Pydantic schema 统一7字段（id/statement/source/supporting_reasoning/falsification_condition/plan/verification_criteria） | 格式漂移，便于自动评价与前端展示 |

### 候选假设的实际输出内容
每条候选假设真实包含：核心陈述 statement（含量化阈值，如“γ-PAC 强度≥0.45 且跨网络耦合熵≤1.2 bit 时主观统一性评分≥7”）；形成依据 source；支持推理 supporting_reasoning；量化证伪条件 falsification_condition（含样本量、统计量、时序约束，如“n≥30 单试次 Granger 分析中 β 定向耦合显著高于 γ 且 β 主导试次仍高一致性报告，则证伪”）；三层研究计划 plan（L1概念框架/L2定量阈值与仪器/L3稳健性替代方案与触发条件）；confirm/reject 双阈值验证标准；以及不确定性（由 Critic 的 top_flaw/missing_evidences 外挂保留，不掩盖）。

## P10｜候选假设核验、比较与筛选方法

### 本作品实际采用的处理方法

| 比较或核验内容 | 本作品如何判断 | 实际产生的处理结果 |
|---|---|---|
| 与科学问题是否相关 | Critic consistency 维度+problem_skelton 对照 | V1 7.3 → V2 7.6 |
| 与已有证据是否一致 | Critic evidence 维度（核查 supporting_reasoning 与 evidence_list 对应） | V1 6.8 → V2 7.8，驱动 V2 补交叉验证设计 |
| 是否存在冲突或错误引用 | 程序溯源统计（来源分布/ID完整）+Critic 审查 | 发现并修复旧版“top-5 被单一来源垄断”问题 |
| 是否可检验、可证伪 | falsifiability 维度+schema 强制字段 | V1 8.2 → V2 9.2 |
| 是否与其他候选假设重复 | cross_hypothesis_comparison 强制输出差异化说明 | 三条假设分处毫秒级/发育级/功能级三个尺度 |
| 是否值得进入研究计划设计 | overall+粒度 L1–L3 | 三条均进入计划生成（无硬淘汰） |

### 筛选结果如何形成
本作品不硬删除假设，而是“全部保留+Critic 排序+缺陷驱动修订”：保留意味着不掩盖第一轮的弱版本（P15 原样保留 V1 结果）。例：V1-H1 把 γ 同步预设为“充分且必要”，Critic 指出缺乏 β 频段等替代通路排除；团队（系统）没有删除 H1，而是在 V2 将 γ-PAC 重写为“高信息带宽通路之一”，并内置“β 主导且 γ 弱时情绪仍可稳定报告即证伪必要性”的否定分支——被保留且被升级。相反，若某假设连续两轮 evidence<5 且 missing_evidences 无法由现有检索层补齐，则降级为“交研究者判断”（本轮未触发）。

## P11｜研究计划生成与假设验证路径

### 本作品如何把假设转化为研究计划

| 计划环节 | 本作品实际生成的内容 | 与候选假设的关系 |
|---|---|---|
| 明确待验证的预测 | verification_criteria.confirm/reject 量化双阈值（如 r≥0.52,p<0.001；三模态同步概率≥73%） | 预测直接来自假设的 mechanism 变量 |
| 确定所需数据、资料或实验条件 | plan.L2 列样本量与仪器（n=35 EEG-fMRI；n=15 尸检脑组织 EPIC+CODEX；n=25 Wernicke 失语 FACS v2023+ECG+IAT） | 数据需求由证伪条件反推 |
| 形成研究步骤和分析方法 | L1概念建模→L2定量阈值→L3稳健性替代（Granger因果、SEEG交叉验证、TMS双盲对照、猕猴纵向模型、fMRI迁移解码） | 三层对应“为什么测/测什么/测不成怎么办” |
| 说明不同结果分别支持或反对什么 | confirm/reject 双阈值+counterfactual（组合否定条件） | 每个结果分支都有预定义解释 |
| 设置停止、回退或补充证据条件 | L3 触发条件（SNR<3 启用 SEEG；招募困难启用 fMRI 解码）；Critic missing_evidences 列需补证据 | 计划自带回退路径 |

### 可执行性
- **团队如何检查研究计划是否具体、可复核**：粒度统计 L2/L3 要求出现样本量、统计阈值、仪器/范式名称，否则低分驱动下轮补充；V2 的 L3 由 5.01 升至 6.5 即该检查的直接结果。
- **研究计划中哪些内容已经具备执行条件，哪些仍是建议**：已具备=文献检索、证据组织、假设与计划生成、自动评价、快照复现（本系统内可立即执行）；仍是建议=全部湿实验/临床样本/电镜/ TMS 实验部分，需领域专家与实验条件，作品明确标注。
- **本作品如何避免用“进一步研究”等空泛表述代替研究步骤**：schema 不允许 plan 为空或无阈值；Critic detailed_review 对空泛表述显式批评（V1 评审中“缺乏排他性检验设计”即此类批评，直接触发 V2 的竞争机制排除模块）。
